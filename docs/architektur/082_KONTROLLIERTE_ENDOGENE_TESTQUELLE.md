# Kontrollierte endogene Testquelle

## Status

Technische Vorarbeit auf Evidenzstufe E0. Keine neue Organismusmechanik.

## Zweck

Der Vertrag 081 hat endogenen Eigenkontakt als offene Rezeptorherkunft
zugelassen. Für die nächste technische Prüfung wird eine reproduzierbare
Quelle benötigt, ohne bereits reale Körperzustände auszuwählen oder
künstliches Rauschen als Innenleben auszugeben.

`ControlledEndogenousSource` beschreibt deshalb nur eine endliche Folge aus:

- expliziten Zeitintervallen;
- stabilen lokalen Trägeridentitäten;
- vollständig vorgegebenen normierten Kontaktwerten.

Die Quelle erzeugt weder Bedeutung noch Zufall. Wiederholtes Öffnen derselben
Quelle ergibt bitgleich dieselben abgeschlossenen Rezeptorzustände.

## Mehrere Zeitskalen

Die Referenzquelle besitzt zwei technische Träger mit unterschiedlich
verlaufenden Folgen. Die Träger heißen nur `c0` und `c1`. Sie stehen nicht für
Temperatur, Schmerz, Müdigkeit, Stimmung oder eine andere vorgegebene
Körperkategorie.

```text
c0: langsamer kontrollierter Verlauf
c1: schneller kontrollierter Verlauf
```

Die Benennung der Zeitskalen gehört nur zur Testwelt und gelangt nicht in den
Rezeptorzustand. Das gemeinsame Feld erhält ausschließlich Herkunft,
Geometrie, lokale Trägeridentität, Zeitfenster und Werte.

## Gemeinsamer Feldweg

Die technische Prüfung bestätigt:

```text
äußerer kontrollierter Kontakt --\
                                  -> Rezeptorenverteiler
endogener kontrollierter Kontakt -/  -> gemeinsame MCM-Neuronenschicht
```

Beide Herkünfte werden in einem atomaren Feldschritt verarbeitet. Ihre Werte
bleiben lokal getrennt und werden vom Verteiler weder gemittelt noch
klassifiziert. Es existiert weiterhin nur ein gemeinsames MCM-Feld.

## Nicht gezeigt

Die Vorarbeit zeigt nicht:

- dass ein realer Organismuszustand angeschlossen ist;
- dass endogener Kontakt dauerhaft vorhanden ist;
- dass das Feld eine Stimmung entwickelt;
- dass mehrere Zeitskalen organisches Memory erzeugen;
- dass Kontaktmaterial auf endogene Werte reagieren soll;
- dass Reflexion oder innere Wahrnehmung vorhanden ist.

Insbesondere darf die kontrollierte Folge nicht als Beweis einer biologischen
Grundaktivität gelesen werden. Sie ist nur eine bekannte technische Ursache,
mit der spätere Wirkungen voneinander getrennt werden können.

## Nächster Schritt

Als Nächstes wird passiv geprüft, ob das bestehende Feld äußere und endogene
Ursachen gleichzeitig lokal bewahrt oder ob eine Ursache die andere bereits
durch feste Diffusion und schnellen Nachhall überdeckt.

Erst nach dieser Nullprüfung darf entschieden werden, ob der endogene Kontakt
bei der Suche nach einer natürlichen Materialbewegungsursache relevant ist.
