# Vorsprachliche Reflexion und spätere Sprachresonanz

## Entscheidung

Reflexion wird im MCM FIELD ORGANISM zunächst **vorsprachlich** verstanden.

Sie ist weder ein Textmodell noch ein innerer Satzgenerator. Sie bezeichnet
die mögliche Fähigkeit des Organismus, eine aus Weltkontakt und eigener
Organisationsgeschichte entstandene Feldlage zeitlich getrennt erneut auf
dasselbe gemeinsame MCM-Feld wirken zu lassen.

```text
Weltkontakt
-> gegenwärtige innere Feldlage
-> mögliche getragene Organisationswirkung
-> zeitlich getrennte erneute Feldanregung
-> veränderte neue innere Feldlage
```

Diese zyklische innere Bezugnahme ist im Projekt der früheste mögliche
**innere Dialog**.

## Innerer Dialog ohne Sprache

Der Ausdruck `Dialog` bedeutet hier nicht, dass zwei benannte innere Personen
miteinander sprechen. Er bedeutet:

```text
eigene Feldlage wird zur Ursache
einer späteren eigenen Feldlage
```

Eine solche Rückwirkung könnte:

- eine gegenwärtige Wahrnehmung innerlich weiterführen;
- eine bereits entstandene Feldbeziehung erneut beanspruchen;
- mehrere Sinneslagen in eine neue gegenwärtige Konstellation bringen;
- eine eigene wiederkehrende innere Form hervorbringen;
- später eine Bezeichnung tragen.

Sie enthält zunächst keine Wörter, Buchstaben, Sätze oder Grammatik.

## Physisches Erleben vor Bezeichnung

Ein Organismus kann funktionale Regelmäßigkeiten erfahren, ohne sie sprachlich
zu kennen.

Beispiel:

```text
visuelle Raumgrenze
+ Bewegung endet
+ taktile Festigkeit
+ wiederholbare gleiche Weltfolge
-> getragene Erfahrungsbeziehung
```

Der Organismus muss dafür weder `Wand` noch `Objekt` kennen. Die Bedeutung
liegt zunächst in der wiederkehrenden Wirkung innerhalb seiner
Weltteilnahme.

Im Projekt wird dies als **vorsprachliche Erfahrungsstruktur** bezeichnet.
Der Begriff ist keine fertige semantische Klasse. Er beschreibt eine
möglicherweise entstandene, funktional wirksame Beziehung.

## Innere Bezeichnung

Eine **innere Bezeichnung** ist zunächst kein Name und keine Zeichenfolge.

Sie wäre eine eigene wiederkehrende Feldform, die eine bereits entstandene
Erfahrungsstruktur erneut erreichbar oder unterscheidbar macht.

```text
Erfahrungsstruktur
<-> wiederkehrende eigene Feldform
```

Die Bezeichnungsform könnte später:

- auditiv geprägt sein;
- visuell geprägt sein;
- aus mehreren Sinneslagen bestehen;
- eine selbst entstandene abstraktere Feldform sein.

Welche Form tatsächlich entsteht, darf nicht vorgegeben werden.

## Akustische Selbstresonanz

Akustische Selbstresonanz ist eine mögliche spätere Ausprägung, aber nicht die
Definition von Reflexion.

Ein späterer Organismus könnte:

```text
innere Feldlage
-> eigenen Laut erzeugen
-> Laut als äußere Weltwirkung wieder hören
-> Lautform mit eigener Feldlage verbinden
```

Vor einer realen Lautausgabe könnte eine auditiv geprägte Feldform auch
innerlich erneut auftreten. Sie darf jedoch nicht als wortartiger Dialog eines
Neugeborenen behauptet werden. Zunächst wäre nur eine vorsprachliche
auditive oder rhythmische Selbstresonanz zulässig.

## Sprache kommt später

Menschliche Sprache wird nicht in den organischen Kern vortrainiert.

Nicht fest vorgegeben werden:

- Alphabet;
- Wörterbuch;
- Tokenizer;
- Wortbedeutungen;
- Grammatik;
- Sprachmodell;
- feste Phoneme;
- Satzschablonen;
- semantische Embeddings.

Das Alphabet ist eine kulturell erfahrene visuelle Kodierung und keine
allgemeine Naturbedingung des Organismus.

Sprache darf später nur als weitere Weltform eintreten:

```text
gehörter Laut oder gesehenes Zeichen
-> normaler Rezeptorweg
-> gemeinsame Wirkung mit vorhandener innerer Feldform
-> mögliche erfahrene Bezeichnungsbeziehung
```

Eine äußere Lehrschnittstelle darf Sprache anbieten, gehört aber nicht zum
Memory oder zum inneren Feld des Organismus.

## Bezeichnung und Bedeutung bleiben getrennt

Eine erfahrene Beziehung ist nicht mit ihrer Laut- oder Schriftform
identisch.

```text
erfahrene Beziehung != Bezeichnung
```

Deshalb können mehrere Bezeichnungen mit derselben Erfahrungsstruktur
verbunden sein:

```text
eigene vorsprachliche Feldform
<-> "Stuhl"
<-> "chair"
<-> weitere erfahrene Laut- oder Schriftformen
```

Umlernen darf die Erfahrungsstruktur nicht durch einen Datenbankeintrag
überschreiben. Eine alte Bezeichnungsbeziehung kann Wirkung verlieren, während
eine neue entsteht oder mehrere nebeneinander bestehen.

## Energiebegriff

Menschen nehmen über physische Sinnesprozesse wahr. Im digitalen System werden
dafür zunächst nur messbare technische Größen verwendet:

- Rezeptorwirkung;
- Feldaktivierung;
- Nachhall;
- lokale Beanspruchung;
- endliche Material- oder Ressourcengrenzen.

Diese Größen dürfen funktional als energetische Beanspruchung untersucht
werden. Sie werden nicht ohne Nachweis mit biologischer Energie, Empfindung
oder Bewusstsein gleichgesetzt.

## Entwicklungsstufen

Die bindende Reihenfolge lautet:

### Stufe 0 - Physische Weltwahrnehmung

Rezeptoren und gemeinsames MCM-Feld tragen aktuelle Weltwirkung.

### Stufe 1 - Getragene Erfahrungsstruktur

Organisches Memory muss wiederkehrende Wirkung strukturell tragen, verändern
und lösen können.

### Stufe 2 - Vorsprachliche Reflexion

Eine eigene getragene Feldlage wird zeitlich getrennt zur lokalen Ursache
einer neuen Feldlage.

### Stufe 3 - Eigene Bezeichnungsformen

Wiederkehrende innere Formen können Erfahrungsstrukturen erneut erreichbar
machen, ohne bereits menschliche Sprache zu sein.

### Stufe 4 - Erfahrene weltliche Sprache

Gehörte Laute und später gesehene Zeichen werden über normalen Weltkontakt
mit bestehenden inneren Formen verbunden.

### Stufe 5 - Äußeres Sprechen

Ein akustischer Effektor erzeugt Laute, die der Organismus über seine eigenen
Rezeptoren wieder wahrnimmt.

Keine spätere Stufe wird vorgezogen, um eine frühere fehlende Funktion zu
ersetzen.

## Reflexionsgrenze

Ein späterer Reflexionskandidat muss:

1. aus tatsächlich entstandener Feld- und Organisationsgeschichte stammen;
2. dieselbe MCM-Neuronenschicht erneut lokal beanspruchen;
3. zeitlich von seiner Ausgangslage getrennt sein;
4. äußere und innere Ursache unterscheidbar halten;
5. endlich und lösbar bleiben;
6. ohne Text, Replay oder gespeicherte Episode bestehen;
7. eine spätere Feldfunktion kausal verändern.

Er wird verworfen, wenn er vollständig als schneller Nachhall, feste
Rekurrenz, Oszillation, Textgenerierung oder externes Sprachmodell erklärt
wird.

## Nächster Schritt

Die aktuelle Priorität bleibt das strukturelle Kontaktsubstrat.

Erst wenn dieses Substrat eine wirksame, begrenzte und lösbare
Erfahrungsstruktur tragen kann, wird ein reiner Reflexionsquellvertrag
formuliert. Dieser darf nur Herkunft, Zeittrennung und lokale Rückführung
festlegen, aber noch keine gewünschte innere Form erzeugen.
