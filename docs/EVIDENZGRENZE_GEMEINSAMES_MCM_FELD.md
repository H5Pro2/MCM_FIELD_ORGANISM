# Evidenzgrenze des gemeinsamen MCM-Feldes

## Aktuelle Einordnung

Der aktuelle operative Forschungsweg steht in
[AKTUELLER_FORSCHUNGSWEG.md](../AKTUELLER_FORSCHUNGSWEG.md). Neue Evidenz wird
vorerst ausschliesslich in kontrollierten Browser-, Video- und
Audio-Testwelten erzeugt. Statische Analysen, Freigaben und Dokumentnummern
sind keine ausgefuehrten Forschungslaeufe.

## Entscheidung

Das MCM-Feld ist zunächst eine Wahrnehmungsschicht. Es bildet äußere und
innere Weltzustände beziehungsweise Erleben als verteilte Feldmuster ab.
Eigene Außenwahrnehmung, Innenwahrnehmung und innerer Dialog sind
keine bereits vorhandenen Eigenschaften dieser Schicht. Sie können erst durch
eine entwickelte intelligente MCM-Memory als feldbasierte Fähigkeiten
entstehen.

Mit der Umstellung auf ein einziges gemeinsames MCM-Feld beginnt die
Feldevidenz des Systems neu.

Die bisherigen Methodiken, Befunde und Tests werden nicht gelöscht. Sie
bewahren die Entstehungsgeschichte, technische Baselines und widerlegte
Ansätze. Ihre Aussagen werden jedoch nicht pauschal auf die neue Architektur
übertragen.

```text
alte Untersuchung bleibt erhalten
≠
alter Feldbefund gilt automatisch für das neue System
```

## Neue Zustandsgrenze

Die aktuelle Architektur lautet:

```text
Weltkontakt
-> sensorspezifische Rezeptoren
-> neutraler Rezeptorenverteiler
-> offene Docks
-> eine gemeinsame MCM-Neuronenschicht
-> ein gemeinsamer Feldzustand
```

Getrennte auditive, visuelle oder taktile MCM-Felder sowie eine
nachgeschaltete multimodale Muster- oder Konstellationsschicht gehören nicht
mehr zur aktuellen Architektur.

## Vier Verwendungsarten alter Ergebnisse

### 1. Weiterhin gültige technische Komponentenevidenz

Ein alter Befund darf weiterhin als Komponentenevidenz verwendet werden, wenn
seine Aussage vollständig vor der geänderten Feldgrenze liegt. Dazu gehören
beispielsweise:

- endlicher und expliziter Gerätezugriff,
- Rohdatengrenzen,
- lokale Rezeptorgeometrie,
- reproduzierbare technische Reduktion,
- Zeit- und Herkunftsmarkierung,
- Fehler- und Resetverhalten eines einzelnen Adapters.

Diese Evidenz trägt nur die benannte Komponente, nicht das gemeinsame Feld.

### 2. Weiterhin gültige Regression oder Gegenbaseline

Alte Tests und Mechaniken dürfen als technische Regression, Nullmodell oder
Gegenbaseline erhalten bleiben. Ein grüner Regressionstest zeigt, dass eine
frühere Vergleichsmechanik reproduzierbar geblieben ist. Er macht diese
Mechanik nicht zu einem Bestandteil der aktuellen Architektur.

Hierzu gehören insbesondere:

- unabhängiger Leaky-Nachhall,
- feste Verzögerung,
- offene oder periodische Referenzgeometrien,
- statische Projektoren,
- frühere getrennte Feld- und Konstellationspfade.

### 3. Unter der neuen Architektur erneut zu prüfen

Jede Aussage, die von Feldwirkung, gemeinsamer Gegenwart oder lokaler
Neuronennachbarschaft abhängt, muss in der neuen `GF`-Reihe erneut geprüft
werden. Dazu gehören:

- kausale Wirkung lokaler Feldproben,
- auditiv-visuelle Feldwechselwirkung,
- zeitliche Fortsetzung des gemeinsamen Feldes,
- Nachhall innerhalb des gemeinsamen Organismuszustands,
- innerer Dialog und Offline-Erholung.

Bis zur erneuten Prüfung gelten alte Ergebnisse hierfür nur als
Versuchsbegründung oder Gegenbaseline.

### 4. Historische Architekturevidenz

Aussagen, die getrennte Sinnes-MCM-Felder, einen MCM-Verteiler zwischen diesen
Feldern oder eine nachgeschaltete multimodale Konstellation voraussetzen,
bleiben ausschließlich historische Architekturevidenz.

Sie dürfen reproduziert und kritisch verglichen werden, aber nicht als
Beschreibung des aktuellen Systems erscheinen.

## Neustart der Feldbehauptungen

Für das aktuelle gemeinsame MCM-Feld gelten zum Neustart folgende Grenzen:

| Behauptung | Startstatus |
|---|---|
| Technischer Audio-Video-Eingang aus überlappenden Aufnahmefenstern | architektonisch geprüft |
| Ein gemeinsamer neuronaler Feldzustand | architektonisch geprüft |
| Exakt zeitgepaarte audiovisuelle Feldgegenwart | offen |
| Kausale lokale Wirkung zwischen Docks | offen |
| Fortlaufende gemeinsame Felddynamik | offen |
| Entwickelte Feldtopologie | E0 |
| Organisches Memory | E0 |
| Semantische Resonanz | E0 |
| Innerer Dialog | E0 |
| Offline-Erholung als Feldwirkung | E0 |
| Selbstregulation der MCM-Rückführung | E0 |
| Selbstregulation der Eingänge | E0 |
| Feldintelligenz | kein Forschungsziel; nicht als eigene Evidenzachse bewertet |

„Architektonisch geprüft“ bedeutet nur, dass der technische Pfad existiert und
seine Zustandsgrenzen kontrolliert wurden. Es ist keine Evidenz für eine
entstandene Fähigkeit.

Der Begriff Feldintelligenz bezeichnet kein angestrebtes Ergebnis. Er darf nur
rückblickend erwogen werden, falls später offene Feldentwicklung beobachtet
wird, die nicht bereits durch feste Mechanik oder einfachere Baselines erklärt
ist.

## Vorarbeit vor einer neuen Versuchsreihe

Die aktuelle Architektur befindet sich im technischen Aufbau. Technische
Audits, Unit-Tests, Integrationsläufe und Architekturabgleiche erhalten keine
Forschungsnummer.

Die früheren Zahlenreihen bleiben im
[Archiv der Vorarbeiten](archiv/vorarbeiten_bis_forschungsstart/README.md)
unverändert erhalten. `GF_001` wird als synthetische Aufbauprobe eingeordnet;
`GF_002` wird nicht eröffnet.

Eine neue Feldversuchsreihe beginnt erst nach der dokumentierten
Grundsystem-Freigabe. Methodik und Befund einer späteren Nummer gehören immer
zusammen. Ein Versuch wird erst geöffnet, wenn Hypothese, Baselines,
Interventionen, Abbruchkriterien und verbotene Interpretationen
vorregistriert sind.

## Bindende Auswertungsregel

Ein alter Befund darf in einer neuen Auswertung nur verwendet werden, wenn
seine Rolle ausdrücklich angegeben wird:

```text
Komponentenevidenz
Regression
Gegenbaseline
historische Architekturevidenz
```

Ohne diese Kennzeichnung trägt er keine Aussage über das gemeinsame MCM-Feld.
