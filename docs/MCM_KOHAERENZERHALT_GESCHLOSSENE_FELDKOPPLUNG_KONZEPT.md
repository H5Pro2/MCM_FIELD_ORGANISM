# MCM-Kohaerenzerhalt unter geschlossener Feldkopplung

## Status

Dieses Dokument ist ein Konzept- und Forschungsrahmen. Es ist kein
MCM-Memory-Nachweis, keine Runtimefreigabe und keine Behauptung einer
Systemfaehigkeit. Es uebersetzt die aus Biocomputing relevante
Ordnungsintuition in technische MCM-Begriffe.

Gesperrt bleiben:

- Selbsterhaltungstrieb als Projektbegriff;
- Bewusstsein, Erleben, Feldintelligenz oder KI als Projektbehauptung;
- biologische Eigenschaften als direkte Eigenschaften der MCM;
- Reward, Zieltopologie oder externe Bewertung als versteckte Memorymechanik;
- jede Aussage, dass hypothetische MCM-Memory bereits vorhanden ist.

## Kernidee

Die fachlich nutzbare Idee lautet:

> Ein lokal gekoppeltes Feldsystem reagiert nicht nur passiv auf Eingaben. Es
> kann seine interne Ordnung so veraendern, dass spaetere Eingaben unter
> vergleichbarer Weltkopplung stabiler, strukturierter oder weniger stoerend
> aufgenommen werden.

Fuer MCM wird daraus keine biologische Behauptung, sondern eine technische
Hypothese:

```text
Weltkontakt
-> gemeinsame technische Feldzeit
-> lokale Feldspannung oder Stoerung
-> Belastung einer endlichen lokalen Ressource
-> lokale Umordnung
-> spaetere veraenderte Feldaufnahme
```

Diese Kette ist nur dann forschungsfaehig, wenn jeder Pfeil messbar,
abgrenzbar und falsifizierbar ist.

## Begriff: Kohaerenz

Kohaerenz bezeichnet hier keine Bedeutung, kein Erleben und keine
Zielerfuellung. Kohaerenz ist eine technische Eigenschaft eines Feldverlaufs:

- lokale Feldwerte bleiben innerhalb definierter Grenzbereiche;
- Folgeeingaben erzeugen geringere ungeregelte Feldspannung;
- gleiche oder verwandte Kontakte fuehren zu reproduzierbarer lokaler
  Aufnahme;
- konkurrierende Kontakte erzeugen messbare Interferenz statt globale
  Ueberschreibung;
- belastete Ressourcen koennen abgeschwaecht und wieder freigegeben werden.

Kohaerenz ist damit ein Messrahmen fuer Feldordnung unter Weltkontakt, keine
Faehigkeitsbeschreibung.

## Relaxation, Musterbildung und uebergeordnete Feldlage

MCM-Feldordnung wird nicht als selbsttaetige Ordnung ohne Ursache untersucht.
Sie ist eine moegliche kausale Folge aus Eingang, aktueller Feldlage, lokaler
Wechselwirkung und Rueckfuehrung. Der neutrale Feldrand dient nur als
technischer Referenzzustand. Ein Abklingen zu diesem Rand ist Relaxation und
noch kein eigener Ordnungsbefund.

Musterbildung verlangt darueber hinaus reproduzierbar unterscheidbare
Feldlagen, die aus kontrolliert unterschiedlichen Einwirkungen oder
Vorgeschichten hervorgehen. Mustererweiterung und nicht vorgegebene neue
Feldlagen bleiben offene Beobachtungsmoeglichkeiten; sie werden nicht als
Zielzustand einprogrammiert.

Eine spaetere technische Innenwahrnehmung wird nur als Arbeitshypothese einer
uebergeordneten Feldlage gefuehrt: Mehrere lokale Feld- und Substratzustaende
muessten gemeinsam die Aufnahme nachfolgender Einwirkungen kausal veraendern.
Vor einer solchen Aggregation muss zuerst eine einzelne lokale Wirkung gegen
ihre Baselines bestehen. Menschliche oder psychologische Zustandsbezeichnungen
sind kein Teil dieses technischen Zustandsraums.

## Abgrenzung gegen Reward

Klassisches Reward-Lernen legt eine externe Bewertungszahl fest und optimiert
Verhalten gegen diese Zahl. Der hier gemeinte MCM-Pfad darf so nicht gebaut
werden.

Nicht zulaessig:

```text
Aktion -> Reward -> direktes Schreiben einer Zielstruktur
```

Zulaessiger Forschungsrahmen:

```text
Kontakt -> lokale Feldspannung -> Ressourcenbelastung
-> lokale Umordnung -> spaetere Feldaufnahme
```

Der Unterschied ist entscheidend: Die Ordnung soll nicht aus einer externen
Belohnung kommen, sondern aus der technischen Feldkopplung selbst. Eine
Umordnung ist nur dann relevant, wenn sie spaeter im Feld kausal lesbar bleibt
und zugleich wieder loesbar ist.

## Rolle der geschlossenen Kopplung

Ohne geschlossene Kopplung kann das Feld nur auf Eingaben reagieren. Mit
geschlossener Kopplung kann eine Feldfolge spaetere Eingangsbedingungen
veraendern.

Minimaler technischer Kreis:

```text
reduzierter Rezeptorzustand
-> gemeinsames MCM-Feld
-> lokaler Substratkandidat
-> begrenzte Rueckwirkung
-> veraenderte spaetere Eingangs- oder Feldbedingung
-> neue reduzierte Rezeptorzustaende
```

Dieser Kreis darf keine Rohdaten, Labels, Bedeutungen oder Spielziele in das
Feld schreiben. Er darf nur technische Zustands- und Kopplungsbedingungen
veraendern.

## Hypothetische MCM-Memory in diesem Rahmen

Hypothetische MCM-Memory waere in diesem Konzept keine gespeicherte Episode.
Sie waere eine lokal gebundene, spaeter wirksame und wieder loesbare
Feld-Substrat-Ordnung.

Erforderlich waeren mindestens:

1. **Bindung:** Ein Kontakt belastet eine endliche lokale Ressource.
2. **Spaetwirkung:** Eine spaetere vergleichbare Probe wird anders aufgenommen.
3. **Abschwaechung:** Wiederholte oder veraenderte Geschichte reduziert die
   gebundene Wirkung messbar.
4. **Interferenz:** Konkurrierende Geschichte beeinflusst die lokale Wirkung
   ohne globale Ueberschreibung.
5. **Freigabe:** Die gebundene Ressource wird technisch wieder verfuegbar.
6. **Wiederbindung:** Eine andere Folgegeschichte kann dieselbe lokale
   Ressource neu beanspruchen.

Ohne diese Rollen bleibt der Befund eine technische Zustandsdifferenz,
Nachhall, Integratorwirkung oder Adapterwirkung.

## Messbare Groessen

Ein MCM-Kohaerenzpfad muss vor jeder Ausfuehrung festlegen:

- welche Feldspannung als Stoerung gilt;
- welche lokale Ressource belastet wird;
- welche Veraenderung der spaeteren Feldaufnahme erwartet wird;
- welche Vergleichsprobe identisch oder verwandt ist;
- welcher Kohaerenzgewinn oder welche Stoerungsreduktion messbar sein muss;
- welche Interferenzfolge den Effekt stoert;
- welche Freigabe- oder Erholungsphase die Ressource wieder verfuegbar macht.

Keine dieser Groessen darf aus einem nachtraeglichen Ergebnistext abgeleitet
werden. Sie muessen vor dem Lauf gebunden sein.

## Gegenbaselines

Der Kandidat muss mindestens gegen diese Erklaerungen bestehen:

- Fixed Adapter aus demselben Anfangszustand;
- Leaky-Nachhall;
- Integrator oder Saettigung;
- Replay oder verdeckter Verlaufspuffer;
- globale Normalisierung;
- externe Reward- oder Zielwertlogik;
- feste Kanten- oder Gewichtsmatrix;
- blosse Raten- oder Schrittzahldifferenz;
- Readout-Artefakt durch unterschiedliche Kausalhistorie.

Erklaert eine Baseline denselben Kohaerenzeffekt vollstaendig, wird der
Kandidat verworfen.

## Konsequenz fuer den naechsten Forschungsabschnitt

Der naechste sinnvolle Abschnitt ist kein grosser Feldlauf. Zuerst braucht der
Kandidat einen Kohaerenzvertrag:

1. Welche lokale Stoerung wird durch Weltkontakt erzeugt?
2. Welche Ressource traegt diese Stoerung?
3. Welche Umordnung ist erlaubt?
4. Welche spaetere Aufnahme muss sich veraendern?
5. Wie wird Abschwaechung gemessen?
6. Wie wird Interferenz gemessen?
7. Wie wird Freigabe und Wiederbindung gemessen?
8. Welche Baseline stoppt den Kandidaten?

Erst danach duerfen Gleichung, Parameter, Runtime oder Feldlauf folgen.

## Zusammenhang mit Biocomputing

Biocomputing liefert fuer dieses Konzept keine direkte Evidenz, aber eine
starke methodische Orientierung: lebende neuronale Kulturen zeigen in
geschlossener Rueckkopplung messbare Ordnungsanpassung. MCM uebernimmt daraus
nicht die Biologie, sondern die technische Leitfrage:

```text
Kann ein digitales MCM-Feldsubstrat lokale Ordnung unter Rueckkopplung so
tragen, dass spaetere Eingaben messbar kohaerenter aufgenommen werden?
```

Diese Frage ist die saubere Fassung der neuronalen Analogie. Sie bleibt offen
und muss im MCM-Projekt eigenstaendig geprueft werden.
