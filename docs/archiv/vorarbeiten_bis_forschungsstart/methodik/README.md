# Historische Methodikreihe 001 bis 037

Die Dateien in diesem Ordner bleiben als unveränderte Forschungsfolge,
Vorregistrierung und Baseline erhalten.

Sie entstanden vor oder während früherer Architekturstände. Begriffe wie
getrennte Sinnes-MCM-Felder, MCM-Verteiler, multimodale Musterprüfung oder
Feldkonstellation beschreiben nicht automatisch die aktuelle Architektur.

Ihre zulässige Verwendung regelt die
[Evidenzgrenze des gemeinsamen MCM-Feldes](../../../EVIDENZGRENZE_GEMEINSAMES_MCM_FELD.md).

Neue Untersuchungen des gemeinsamen Feldes werden nicht hier fortnummeriert.
Sie beginnen getrennt als `GF`-Reihe unter
[`docs/gemeinsames_feld`](../gemeinsames_feld/README.md).
