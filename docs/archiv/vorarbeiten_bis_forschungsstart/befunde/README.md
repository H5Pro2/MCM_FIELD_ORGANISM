# Historische Befundreihe 001 bis 040

Die Befunde in diesem Ordner werden nicht gelöscht, verkürzt oder nachträglich
auf die neue Architektur umgeschrieben. Sie dokumentieren, was unter der
jeweils damaligen Zustandsgrenze tatsächlich geprüft wurde.

Ein alter Befund ist nur dann weiterhin aktuelle Komponentenevidenz, wenn seine
Aussage vollständig vor der geänderten Feldgrenze liegt. Feld-, Topologie-,
Memory- oder Semantikaussagen müssen im gemeinsamen MCM-Feld neu geprüft
werden.

Die verbindliche Einordnung steht in der
[Evidenzgrenze des gemeinsamen MCM-Feldes](../../../EVIDENZGRENZE_GEMEINSAMES_MCM_FELD.md).

Neue Feldbefunde beginnen getrennt als `GF`-Reihe unter
[`docs/gemeinsames_feld`](../gemeinsames_feld/README.md).
