# Archiv: Vorarbeiten bis zum Forschungsstart

Dieser Bereich bewahrt die detaillierten Untersuchungen aus der Aufbauphase
von `MCM_FIELD_ORGANISM`.

## Inhalt

- [`methodik`](methodik/README.md): frühere vorregistrierte Komponenten- und
  Architekturprüfungen.
- [`befunde`](befunde/README.md): zugehörige technische Ergebnisse,
  Nullbefunde und Pilotläufe.
- [`gemeinsames_feld`](gemeinsames_feld/README.md): Zeitaudits,
  Zustandsabgleiche, statische Gegenbaselines und die vorläufige
  `GF_001`-Aufbauprobe.

## Einordnung

Die Texte bleiben erhalten, damit technische Entscheidungen, negative
Kontrollen und bekannte Sackgassen nachvollziehbar sind.

Sie bilden keine aktive Forschungsserie des späteren Grundsystems:

- technische Audits sind Vorarbeit,
- frühere Komponentenbefunde werden nicht automatisch auf das gemeinsame
  MCM-Feld übertragen,
- `GF_001` ist eine synthetische Aufbauprobe,
- `GF_002` bleibt geschlossen und wird nicht fortgesetzt.

Der aktuelle Arbeitsstand steht in
[Vorarbeitsstand bis zum Forschungsstart](../../VORARBEITSSTAND.md).
