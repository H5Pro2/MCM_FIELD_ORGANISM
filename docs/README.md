# Dokumentationsübersicht

## Grundlagen

- [Gründungsvertrag](GRUENDUNGSVERTRAG.md): Verbindliche Zustandsgrenze,
  feste technische Bedingungen und gesperrte Mechaniken.
- [Offene Forschungsfragen](FORSCHUNGSFRAGEN.md): Ungeklärte Fragen zu Welt,
  Rezeptoren, Effektoren, Innenfeld, Beziehungen, Ressourcen und Organismus.

## Dokumentationsregel

Dokumentation darf mögliche Zustandsrollen und Prüfbedingungen festhalten. Sie
darf keine unbeobachtete Lernregel, Zieltopologie oder kognitive Funktion als
bereits vorhandene Systemeigenschaft ausgeben.
