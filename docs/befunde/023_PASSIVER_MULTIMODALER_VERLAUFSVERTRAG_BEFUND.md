# Befund 023: Passiver multimodaler Verlaufsvertrag

## Kurzurteil

Der neue Verlaufsbeobachter kann vollständige multimodale Konstellationen als
kausal geordnete Folge prüfen und eine exakte spätere Rückkehr sichtbar machen:

```text
A -> B -> A
```

Im kontrollierten Lauf wurde nur die auditive Feldlage in `B` verändert. Der
Vergleich wies deshalb aus:

```text
A(t0) gegen B(t1): auditiv verändert, visuell unverändert
A(t0) gegen A(t2): auditiv und visuell exakt zurückgekehrt
B(t1) gegen A(t2): auditiv verändert, visuell unverändert
```

Das ist ein Beobachtungsbefund. Der Organismus erkennt oder speichert `A` noch
nicht selbst.

## Getragener Befund

- Die gemeinsame Überlappungszeit jeder Konstellation bildet die Zeitbasis.
- Zeitliche Lücken und überlappende Beobachtungsfenster bleiben unterscheidbar.
- Technisch andere Zeitstempel verhindern keine exakte Feldrückkehr.
- Änderungen werden auf die tatsächlich veränderte Modalität begrenzt.
- Hinzugekommene Modalitäten werden nicht als Inhaltsänderung ausgegeben.
- Eine fortbestehende Modalität kann ihre Anatomie nicht still wechseln.
- Quellkonstellationen bleiben trotz Beobachter unverändert.
- Das Ergebnis hält keine Feldvektoren und keine Konstellationskennung fest.

## Stärkste Gegenposition

Der kontrollierte `A -> B -> A`-Befund folgt vollständig aus einem exakten
Paarvergleich unveränderlicher Vektoren. Er zeigt nicht, dass das Feld selbst
eine Wiederkehr wahrnimmt oder dass es zwei ähnliche, aber nicht identische
Erfahrungen organisch aufeinander beziehen kann.

Die Bezeichnung "Rückkehr" gehört daher ausschließlich zur äußeren
Forschungsbeobachtung.

## Nicht gezeigt

- Wiedererkennen durch den Organismus,
- Toleranz gegenüber natürlicher sensorischer Variation,
- Stabilisierung wiederkehrender Beziehungen,
- geschichtliche Verdichtung,
- Memory-Zeitlagen,
- semantische Resonanz,
- innere Bezeichnung oder Syntax,
- Feldintelligenz.

## Evidenz

```text
passive zeitliche Verlaufsbeobachtung: E2
exakte technische Feldrückkehr:        E2
organisches Wiedererkennen:            E0
geschichtliche Verdichtung:            E0
```

## Bester nächster Schritt

Der nächste Schritt darf nicht einfach eine Ähnlichkeitsschwelle ergänzen.
Zuerst muss konzeptionell geklärt werden, welche bereits vorhandene lokale
Feldwirkung unter natürlicher Variation eine wiederkehrende Beziehung tragen
könnte. Dafür ist eine Nullprüfung mit leicht veränderten Wiederholungen
sinnvoll: Der passive exakte Beobachter muss dort erwartungsgemäß scheitern.
Erst dieser Negativbefund grenzt den offenen Funktionsmangel sauber ein.
