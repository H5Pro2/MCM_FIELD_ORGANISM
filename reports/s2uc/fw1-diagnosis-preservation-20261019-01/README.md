## So arbeitet der Grundpfad

**Audio/Video → Rezeptoren → gemeinsame Wahrnehmungsbindung → getrennte Feld- und Memoryzweige**

Die private Audio-Halbprojektion (NJ) wird genau einmal angewandt.
Feld und Memory erhalten dieselben kanonischen Wahrnehmungswerte.

- **Feld:** verarbeitet Wahrnehmungskontakte unabhängig vom Memoryzweig.
- **`A_RECENT`:** begrenzte jüngere Inhalte in B4 und Fast.
- **`B_STABLE`:** getrennte stabilisierte auditive und visuelle Inhalte.
- **Teilhinweise:** lesen Memory ohne Änderung und liefern eine Hypothese
  oder Enthaltung. Hypothesen werden nicht angewandt.
- **Abschluss:** gebundener Snapshot und reguläres `close()`.

Ein Abruf bezieht sich nur auf **beobachtete Komponenten, Vergleichsregel und
gespeicherte Spur**, nicht auf Objekt- oder Szenenidentität. Der
[historische Playeransicht](reports/s2oe/history-display-qualification-20260912-01/view.html)
macht gespeicherte Vergleichsgrundlagen, Hypothese und Enthaltung sichtbar.
Sie ist ausschließlich lesend, keine laufende Wahrnehmung.

Der private lokale Videoeingang ist im begrenzten Zwei-Durchlauf-Vergleich
technisch bestätigt, ohne dort einen Abrufnutzen nachzuweisen. Weitere
Medienversuche, Schwellenoptimierungen und Komfortausbau sind nicht freigegeben.

Rückgaben → Schließen ist bestätigt. Memory bleibt zwischen Aufrufen erhalten;
Hinweise bleiben read-only. Die Quellen wurden wiederverwendet. Offener Liveeingang,
allgemeiner Dauerbetrieb und allgemeine Crash-Recovery sind nicht nachgewiesen.
