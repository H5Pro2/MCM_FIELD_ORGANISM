## Stopp: vollständige Anschlussfreigabe noch nicht begründet

Beim abschließenden lesenden Klassenabgleich zeigt sich ein Fehler in
`tools/_structure_comparison.py::ledger`: referenzierte Dateien gehen nur
in die Gesamtsumme ein, nicht in ihre jeweilige Belegklasse. Der neue
Bindungseintrag behauptet deshalb eine unvollständige Metadatendeckung.
Die gespeicherte QUALIFIED-Angabe bezeichnet die bestandenen zwölf Tests,
nicht eine nachträglich behauptete vollständige Budgetqualifikation.

Aktive Referenzen ohne neue Hauptbindung, physisch einmal gezählt:

| Klasse | Byte |
| --- | ---: |
| Software, Tests, Quelldokumente | 329.991 |
| Quellen-/native Ergebnisbelege | 389.485 |
| Metadaten | 25.787 |
| Verifikationsbelege | 535 |

Die ausgewiesenen 47.114 Byte Laufmetadaten einschließlich 12.288 Byte
Bindungs-/Berichtreserve lassen die 25.787 Referenzmetadaten aus.
Mit diesen beträgt dieselbe konservative Rechnung **72.901 / 65.536 Byte**,
also **7.365 Byte über der Grenze**. Dabei ist die Hauptbindung nur einmal
innerhalb der 12.288-Byte-Reserve angesetzt; davon bleiben nach 11.649 Byte
noch 639 Byte für einen Bericht. Dieser geringe Rest ist keine ausreichend
begründete vollständige Abschlussreserve.

Die Rechnung setzt Erfolgs- und Fehlerdateien gleichzeitig maximal an.
Das beweist nicht, dass jeder erreichbare Abschluss die Grenze überschreitet:
Nur Erfolg oder Fehler ohne Auswertung ergäben mit derselben Reserve jeweils
56.517 Byte. Die tatsächlich erreichbaren Fehleralternativen müssen jedoch
aus dem Abschlusscode vollständig hergeleitet und geprüft werden, statt
nachträglich nur eine passende Auswahl anzusetzen. Keine Umklassifizierung
und keine Grenzerhöhung vorgenommen.

Eine zweite Begrenzung betrifft die Arbeitsvorbindung: 19.008 Differenzen
sind im Code pro vollständigem Vergleich durchgesetzt. Die Qualifikation
enthielt zusätzlich die eigenständige Nullform- und Arithmetikprüfung.
Statisch aus den erreichten Aufrufen ergeben sich 32.256 neutrale
Differenzen insgesamt (19.008 + 12.672 + 576), keine neu gemessene Zahl.
Die Vorregistrierung unterschied diese Gesamtarbeit nicht ausdrücklich
von der Grenze eines einzelnen Vergleichs. Auch die zusätzlichen
Verifikatoraufrufe der Manipulationstests benötigen eine explizite
Qualifikations-Gesamtbilanz. Eine eingehaltene Einzelaufrufgrenze ersetzt
diese nicht.
